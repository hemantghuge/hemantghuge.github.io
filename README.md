# Hemant Ghuge - Personal Portfolio

Welcome to the repository for my personal portfolio website. This site showcases my journey as a Senior AI Engineer and aspiring Product Manager, highlighting my expertise in computer vision, edge AI, and end-to-end product delivery.

**Live Site:** [**hemantghuge.github.io**](https://hemantghuge.github.io)

---

## ✨ Features

-   **Responsive Design:** Fully responsive and mobile-first design ensures a seamless experience on all devices.
-   **Dynamic Content:** Interactive elements like animated counters, hover effects, and smooth scrolling animations.
-   **Comprehensive Sections:**
    -   **Home:** A hero section with key achievements and animated metrics.
    -   **About:** A deeper dive into my background, skills, and mindset.
    -   **Projects:** A filterable gallery of my work in AI, Product Management, and more.
    -   **Resume:** An embedded, downloadable PDF of my professional resume.
    -   **Contact:** A functional contact form for easy communication.
-   **SEO Optimized:** Carefully crafted meta tags for better search engine visibility and social sharing.
-   **Clean Code:** Built with modern web standards and best practices.

---

## 🛠️ Tech Stack

This portfolio is built with a simple yet powerful stack:

-   **Frontend:** HTML5, JavaScript (ES6+)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/) for a utility-first CSS framework.
-   **Icons:** [Font Awesome](https://fontawesome.com/)
-   **Fonts:** [Google Fonts](https://fonts.google.com/) (Poppins & Inter)
-   **Deployment:** [GitHub Pages](https://pages.github.com/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You just need a modern web browser.

### Installation

1.  Clone the repo:
    ```sh
    git clone https://github.com/hemantghuge/hemantghuge.github.io.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd hemantghuge.github.io
    ```
3.  Open `index.html` in your browser to view the website.
